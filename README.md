# NetPulse

NetPulse is a network monitoring and analysis dashboard designed to provide real-time visibility into network performance, telemetry, alerts, predictions, anomalies, route risks, and automated network actions.

## Features

- Network Dashboard
- Real-Time Telemetry
- Performance History
- Alerts
- Predictions
- Anomaly Detection
- Route Risk Analysis
- Self-Healing Rules
- Network Simulation & Demo
- Network Topology

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
